<Meta title="Foundations/Radius" />

export const presetVars = (density) =>
  Object.fromEntries(Object.entries(scaleRadius(density)).map(([key, value]) => [`--mari-radius-${key}`, value]));

# Radius

Köşe yuvarlaklığı `@mari-ui/tokens` `radius` skalasından gelir; Tailwind'in
`rounded-sm/md/lg/xl` utility'leri `--mari-radius-*` değişkenlerine bağlıdır.
Varsayılan **yuvarlak** (`md`); marka daha keskin ya da daha yumuşak bir karakter
istiyorsa `mari-ui.config.json`'da tek bir ayarla bütün skala orantılı değişir:

```json
{ "density": { "radius": "none" } }
```

## Preset'ler

Aşağıdaki her sütun GERÇEK component'lerdir; sadece `--mari-radius-*` değişkenleri
preset'e göre ayarlanmıştır.

<div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fit, minmax(210px, 1fr))", gap: "16px", margin: "20px 0" }}>
  {radiusDensities.map((density) => (
    <div key={density} style={{ ...presetVars(density), display: "flex", flexDirection: "column", gap: "12px" }}>
      <code style={{ fontSize: "12px" }}>
        {density}
        {density === "md" ? " (varsayılan)" : ""}
      </code>
      <Card size="sm" title="Sipariş #1042">
        <div style={{ display: "flex", flexDirection: "column", gap: "8px" }}>
          <Input placeholder="E-posta" />
          <div style={{ display: "flex", gap: "8px", alignItems: "center" }}>
            <Button variant="solid" color="primary">Kaydet</Button>
            <Tag color="success">Onaylandı</Tag>
          </div>
        </div>
      </Card>
    </div>
  ))}
</div>

| Preset | Ölçek | Karakter |
|---|---|---|
| `none` | hepsi 0 | Keskin, kurumsal / editoryal |
| `sm` | ×0.5 | Hafif — veri yoğun paneller |
| `md` | ×1 (varsayılan) | Modern SaaS ana akımı |
| `lg` | ×1.5 | Yumuşak, tüketici uygulaması |

## Kurallar

- **Kontroller** (Button, Input, Select, Tag) → `rounded-md`; **konteynerler** (Card, Modal, Drawer, Dropdown paneli) → `rounded-lg`/`rounded-xl`.
- **İç içe radius:** iç öğenin radius'u = dış radius − aradaki dolgu. İçteki köşe dıştakinden büyük görünmemeli.
- **`rounded-full`** yalnızca geometrik olarak yuvarlak öğelerde (avatar, switch, radio, spinner, nokta rozet) — preset'ten etkilenmez.
- **Göstergeler** (sekme alt çizgisi, seçili satır çubuğu) her zaman radius 0 — köşeli kutuya çizilen kenarlık uçlarda bükülür; ayrı `::before`/`::after` çubuk kullanın.
- Çıplak `rounded` ve `rounded-2xl/3xl` **yasak** — Tailwind'in sabit değerlerine gider, preset'i yok sayar (`lib/radiusTokens.test.ts` bunu CI'da yakalar).
