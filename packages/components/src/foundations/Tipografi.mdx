# Tipografi

Font ölçeği 1.125 (major second) oranıyla, `0.875rem` (14px @ 16px kök) gövde
metni tabanı üzerine kuruludur. Kaynak: `@mari-ui/tokens` `fontSize` /
`fontWeight` / `lineHeight`.

> **Birim kuralı:** tüm boyutlar `rem` — asla `px`. `px` 4K/yüksek-DPI
> ekranlarda kullanıcının kök font ayarıyla ölçeklenmez. Aşağıdaki px
> karşılıkları sadece 16px kök font varsayımıyla referanstır.

## Ölçek

| Anahtar | Boyut (rem) | ≈ px | CSS değişkeni | Tipik kullanım |
|---|---|---|---|---|
| `xs` | `0.75rem` | 12 | `--mari-font-size-xs` | Yardım metni, rozet, sayaç |
| `sm` | `0.875rem` | 14 | `--mari-font-size-sm` | **Gövde metni varsayılanı**, UI etiketleri |
| `md` | `1rem` | 16 | `--mari-font-size-md` | Vurgulu gövde, büyük input |
| `lg` | `1.125rem` | 18 | `--mari-font-size-lg` | Alt başlık (h5/h6) |
| `xl` | `1.25rem` | 20 | `--mari-font-size-xl` | Bölüm başlığı (h4) |
| `2xl` | `1.5rem` | 24 | `--mari-font-size-2xl` | Sayfa başlığı (h3) |
| `3xl` | `1.875rem` | 30 | `--mari-font-size-3xl` | h2 |
| `4xl` | `2.25rem` | 36 | `--mari-font-size-4xl` | h1 / hero |

## Ağırlıklar

| Anahtar | Değer | Kullanım |
|---|---|---|
| `normal` | 400 | Gövde metni |
| `medium` | 500 | Buton, aktif nav öğesi |
| `semibold` | 600 | Başlıklar, kart başlığı |
| `bold` | 700 | Nadiren — güçlü vurgu |

## Satır yüksekliği

| Anahtar | Değer | Kullanım |
|---|---|---|
| `tight` | 1.25 | Başlıklar |
| `normal` | 1.5 | UI metni |
| `relaxed` | 1.75 | Uzun paragraf |

## Kural (Faz 13)

Component'ler kendi `text-*` sınıflarını uydurmaz — boyutu `size` prop'undan
gelen paylaşılan ölçeğe (`lib/sizeClasses.ts` `fontSizeClass`) bağlar.
`Typography` component'i başlık ölçeğinin tek referansıdır.
