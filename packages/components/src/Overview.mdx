# mari-ui

**Yumuşak iris** · Geist arayüz · Manrope başlıklar · Açık ve koyu tema.

[Yeni temayı gerçek bileşenlerle deneyin](?path=/story/foundations-soft-iris--karsilastirma).

Türkçe, token-tabanlı, framework-bağımsız React bileşen kütüphanesi. Renk /
tipografi / spacing tek bir kaynaktan (`@mari-ui/tokens`) türer; light ve dark
tema `data-theme` attribute'u ile, WCAG AA kontrastı otomatik hesaplanır.

Yapı ant.design/components düzenini izler: her sayfada **özet → Ne Zaman
Kullanılır → Playground → varyantlar → API tablosu**. Başlarken **Foundations**
(Renkler, Tipografi, Spacing, Elevation) sayfalarına bakın.
