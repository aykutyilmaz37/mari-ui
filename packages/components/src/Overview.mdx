# mari-ui

**Yumuşak iris** · Geist arayüz · Manrope başlıklar · Açık ve koyu tema.

Türkçe, token tabanlı, framework'ten bağımsız React bileşen kütüphanesi. Renk /
tipografi / boşluk tek bir kaynaktan (`@mari-ui/tokens`) türer; açık ve koyu
tema `data-theme` özniteliğiyle, WCAG AA kontrastı otomatik hesaplanır.

Yeniyseniz **Başlarken / Kurulum** ile başlayın; görsel temel için **Foundations**
(Renkler, Tipografi, Spacing, Elevation). Her component sayfası ant.design düzenini
izler: **özet → Ne Zaman Kullanılır → Playground → gerçek senaryolar → API tablosu**;
"Show code" kopyalanabilir kodu verir.

[Yumuşak iris temasını gerçek bileşenlerle deneyin](?path=/story/foundations-soft-iris--karsilastirma).
