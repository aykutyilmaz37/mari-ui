# AI kuralları

Projenizde Claude Code, Codex, Cursor, Gemini ya da GitHub Copilot ile çalışıyorsanız, `@mari-ui/cli` bu araçlara mari-ui'ı **doğru** kullanmayı öğreten kural dosyalarını yazar. Kurallar elle yazılmaz: kütüphanenin derlenmiş **gerçek** prop sözleşmesinden (`manifest.json`) ve projenizin çözümlenmiş temasından üretilir — böylece ajan, var olmayan bir prop'u ya da kaldırılmış bir API'yi "güncel" sanmaz.

## Komutlar

```bash
npx @mari-ui/cli init     # paketleri package.json'a ekler, mari-ui.config.json ve kural dosyalarını oluşturur
npx @mari-ui/cli sync     # paket sürümü ya da tema değişince kural dosyalarını tazeler
npx @mari-ui/cli sync --check   # hiçbir şey yazmaz; bayat dosya varsa çıkış kodu 1 (CI için)
```

Belirli araçlar için: `--agents claude,cursor`. Tasarım kişiliğiyle başlamak için: `npx @mari-ui/cli init --persona editorial` (bkz. Tema). `init` paket yöneticisini kendisi çalıştırmaz: kurulumdan sonra `npx @mari-ui/cli sync` ile kuralları gerçek manifest'ten tazeleyin.

## Platform: web / native / ikisi

`init` platformu sorar ya da `--platform web|native|both` ile alır; seçim `mari-ui.config.json`a `platform` olarak yazılır.

| Proje | Komut | Paketler |
|---|---|---|
| Web | `init --platform web` | `@mari-ui/components` + `core` + `tokens` |
| Mobil (React Native / Expo) | `init --platform native` | `@mari-ui/native` + `core` + `tokens` |
| Tek pakette web + mobil | `init --platform both` | ikisi + `core` + `tokens` |
| Ayrı uygulamalı monorepo | her uygulamada ayrı: `init --platform web --dir apps/web`, `init --platform native --dir apps/mobile` | uygulamanın kendi platformu |

Native projeye `@mari-ui/components` kurulmaz ve web kuralı mobil kodda kullanılmaz. Platform değişince eski kural dosyaları silinmez; elle temizlenecek dosyalar ve düzeltme adımları: [docs/kurulum-platformlar.md](https://github.com/aykutyilmaz37/mari-ui/blob/main/docs/kurulum-platformlar.md).

## Yazılan dosyalar

Aşağıdaki tablo web içindir. Native'de Claude skill'i `.claude/skills/mari-ui-native/SKILL.md`; `both`ta skill'ler `mari-ui-web` / `mari-ui-native`, Cursor `.cursor/rules/mari-ui-web.mdc` / `mari-ui-native.mdc`, Copilot `.github/instructions/mari-ui-web.instructions.md` / `mari-ui-native.instructions.md` olur.

| Araç | Dosya |
|---|---|
| Claude Code | `CLAUDE.md` + `.claude/skills/mari-ui/SKILL.md` |
| Codex | `AGENTS.md` |
| Cursor | `.cursor/rules/mari-ui.mdc` |
| Gemini | `GEMINI.md` |
| GitHub Copilot | `.github/copilot-instructions.md` |

Kendi içeriğinizi de yazdığınız dosyalarda (`AGENTS.md`, `GEMINI.md`…) mari-ui yalnız `<!-- mari-ui:start -->` ile `<!-- mari-ui:end -->` arasını değiştirir; geri kalanına dokunmaz.

## İçerik

**Kesin kurallar** (her dosyada, kısa):

1. Önce mari-ui — ihtiyacı karşılayan bir component varsa onu kullan, yenisini yazma.
2. Sabit renk yok — renkler `mari-*` token'larından.
3. Sabit px yok — boşluk ve boyut skaladan (`rem`).
4. Gölge, köşe, katman skaladan — keyfi `shadow-[…]`, `rounded-[…]`, `z-[999]` yok.
5. Yüklenme `skeleton` ile — veri gelene kadar component'in kendi iskeleti.
6. Erişilebilirlik temeli — etiketler, rol, klavye.
7. Linkler düz `<a href>` — sayfa geçişi `onNavigate` ile.

**Serbest alanlar** (her dosyada): kesin kurallar yalnız component kullanımı, token ve erişilebilirlik içindir. Sayfa düzeni, kompozisyon ve ifade alanları (hero, arka plan, illüstrasyon, tipografik başlıklar, hareket) projeye göre serbestçe kurulur — her proje aynı iskelete dökülmez.

**Tasarım kişiliği** (her dosyada): projenin seçili kişiliği, fontları, köşe/gölge/hareket karakteri; AI düzeni ve tonu buna göre seçer.

**Sayfa kurma rehberi** (yalnız Claude skill'inde, ilgili işte yüklenir): yeni projede önce **tasarım brief'i** (hedef kitle, ton, referanslar → kişilik + düzen yönü), sonra iş akışı, uygulama iskeleti, sayfa kalıpları (panel, liste + detay, form…), "hangi durumda hangi component" tablosu, tema ve ölçek ipuçları.

Her component'in güncel prop listesi ve kaldırılmış prop'ları da dosyalara girer.
