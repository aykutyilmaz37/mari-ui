# Tema

Tema iki katmanlıdır:

1. **Proje teması** — tasarım kişiliği, marka rengi, font, köşe, boşluk, gölge ve hareket. Geliştirici `mari-ui.config.json`da tanımlar, `npx mari-ui theme` CSS'e çevirir.
2. **Son kullanıcı ayarı** — açık/koyu/sistem, vurgu rengi, yoğunluk. Kullanıcı `ThemeCustomizer` ile seçer; tarayıcıda saklanır.

İkisi de `--mari-*` CSS değişkenleri üzerinden akar: component'ler yeniden derlenmez, değişiklik anında uygulanır.

## Tasarım kişilikleri

Aynı component'lerle kurulan projeler birbirinin kopyası gibi görünmesin diye hazır kombinasyonlar. Bir kişilik renk + font eşleşmesi + köşe + boşluk + gölge + hareketi **birlikte** seçer; Storybook araç çubuğundaki **Kişilik** menüsünden hepsini canlı görebilirsiniz.

| Kişilik | `persona` | Uygun olduğu yerler | Karakter |
|---|---|---|---|
| Kurumsal | `corporate` | Yönetim paneli, finans, B2B, kamu | Lacivert, IBM Plex Sans, küçük köşe, sıkı, yumuşak gölge, sakin hareket |
| Oyunbaz | `playful` | Tüketici uygulaması, eğitim, çocuk, topluluk | Pembe + camgöbeği, Nunito / Baloo 2, büyük köşe, rahat, belirgin gölge, canlı hareket |
| Minimal | `minimal` | Geliştirici araçları, portfolyo, verimlilik | Nötr, Inter, keskin köşe, bol boşluk, gölgesiz |
| Editoryal | `editorial` | Haber, blog, dergi, içerik platformu | Kırmızı vurgu, Source Sans 3 / Fraunces (serif başlık), gölgesiz |
| Lüks | `luxury` | Moda, mücevher, otel, premium hizmet | Altın / koyu, Jost / Cormorant Garamond, keskin köşe, yavaş hareket |

```bash
npx mari-ui init --persona playful   # config'e "persona" yazar (varsa yalnız bu alanı değiştirir)
```

```json
{ "persona": "playful", "color": { "primary": "#0f766e" } }
```

Kişilik **taban** olur; config'te açıkça yazdığınız her alan onu ezer (yukarıdaki örnekte yalnız marka rengi değişir). Fontlar yalnız aile adıdır: web'de `npx mari-ui theme` çıktısındaki Google Fonts bağlantısını `<head>`e ekleyin (tüm aileler Türkçe karakterleri içerir); yüklenmezse sistem fontuna düşülür. React Native'de kişilik fontları paketle gelmez (bilinçli karar): renk, köşe, gölge ve hareket uygulanır, font varsayılan olarak sistem fontunda kalır.

## Proje teması: `mari-ui.config.json`

```json
{
  "color": { "primary": "#6951ce", "accent": "#765991" },
  "typography": {
    "fontFamilySans": "\"Geist\", ui-sans-serif, system-ui, sans-serif",
    "fontFamilyMono": "\"Geist Mono\", ui-monospace, monospace",
    "fontFamilyHeading": "\"Manrope\", \"Geist\", ui-sans-serif, sans-serif"
  },
  "density": { "radius": "md", "spacing": "normal", "shadow": "normal" },
  "motion": "normal",
  "scale": { "fluid": false, "max": 22 }
}
```

| Alan | Değerler | Etkisi |
|---|---|---|
| `color.primary`, `color.accent` | hex | Tek renkten 50–950 rampa üretilir; her rolün dolgu/metin/kenarlık tonları açık ve koyu modda WCAG AA kontrastına göre seçilir. |
| `typography.*` | CSS font ailesi | Gövde, kod ve başlık aileleri. |
| `density.radius` | `none` · `sm` · `md` · `lg` | Tüm köşe skalası orantılı (×0 · ×0,5 · ×1 · ×1,5). Daire/hap şekilleri etkilenmez. |
| `density.spacing` | `compact` · `normal` · `comfortable` | Varsayılan boşluk yoğunluğu (kullanıcı ayarı her zaman önce gelir). |
| `density.shadow` | `none` · `soft` · `normal` · `strong` | Gölgelerin koyuluğu (geometri aynı); `none`da yüzeyler kenarlıkla ayrışır. |
| `motion` | `off` · `calm` · `normal` · `lively` | Tüm geçiş süreleri çarpılır (×0 · ×1,4 · ×1 · ×0,85 + hafif taşan eğri). "Hareketi azalt" tercihi her zaman geçerli. |
| `persona` | `corporate` · `playful` · `minimal` · `editorial` · `luxury` | Yukarıdaki alanların hazır kombinasyonu; açık alanlar onu ezer. |
| `scale.fluid`, `scale.max` | `true` / px | Büyük ekranda kök yazı boyutu akışkan büyür (4K'de `max` px'e kadar). |

```bash
npx mari-ui theme      # mari-ui-theme.css + mari-ui-theme.ts üretir
```

`mari-ui-theme.css`i mari-ui CSS'inden (`@mari-ui/components/tailwind.css` ya da `styles.css`, bkz. Kurulum) **sonra** import edin. `mari-ui-theme.ts` aynı temayı JS objesi olarak verir (React Native ve token'lara koddan erişmek için). Değerleri görerek seçmek için **tema stüdyosu** (`apps/studio`) aynı config'i dışa aktarır.

### Ek temalar

Açık ve koyunun ötesinde isimli temalar tanımlanabilir; her biri `[data-theme="<ad>"]` bloğu olarak üretilir:

```json
{
  "themes": {
    "brand": { "base": "light", "color": { "primary": "#a21caf" } },
    "highContrast": { "base": "dark", "color": { "primary": "#facc15" } }
  }
}
```

`base`, kontrast hesabının yönüdür (açık zemin mi, koyu zemin mi).

## Açık / koyu tema

- `<html data-theme="dark">` koyu, `data-theme="light"` açık; öznitelik yoksa işletim sisteminin tercihi (`prefers-color-scheme`) kullanılır.
- İç içe bölgeler kendi temasını kurabilir: bir kartı `data-theme="dark"` ile sarmak yalnız o bölgeyi koyu yapar.

## Son kullanıcı ayarı: `ThemeCustomizer`

```tsx
"use client";
import { ThemeCustomizer, loadTheme, saveTheme } from "@mari-ui/components/theme-customizer";

<ThemeCustomizer defaultValue={loadTheme()} onChange={saveTheme} />;
```

- Seçim anında uygulanır (`apply`, varsayılan açık); `saveTheme` tarayıcıda saklar.
- Sayfa açılışında kayıtlı ayarın **çizimden önce** uygulanması için `getThemeScript()` `<head>`e konur (bkz. **Başlarken / Kurulum**); React açıldıktan sonra `applyTheme(loadTheme())` aynı değerleri yazar, görünür değişim olmaz.
- Config'te `density.spacing` varsayılandan farklıysa panele verin: `defaultValue={{ spacing: mariTheme.spacingDensity, ...loadTheme() }}`.

```tsx
"use client";
import { useEffect } from "react";
import { applyTheme, loadTheme } from "@mari-ui/components/theme-customizer";

export function ThemeBoot() {
  useEffect(() => applyTheme(loadTheme()), []);
  return null;
}
```

## Token'ları kendi stillerinizde kullanmak

Kendi CSS'inizde aynı değişkenleri kullanın — sabit renk yazmayın:

```css
.ozel-banner {
  background: var(--mari-color-primary-subtle);
  color: var(--mari-color-primary-subtle-contrast);
  border-radius: var(--mari-radius-md);
  box-shadow: var(--mari-shadow-sm);
}
```

Projeniz Tailwind v4 kullanıyorsa Kurulum'daki `@mari-ui/components/tailwind.css` girişi bu sınıfları zaten tanımlar; `bg-mari-surface`, `text-mari-muted`, `rounded-md`, `shadow-mari-md` gibi sınıfları kendi kodunuzda da kullanabilirsiniz. Tüm değişkenler **Foundations** sayfalarında.
