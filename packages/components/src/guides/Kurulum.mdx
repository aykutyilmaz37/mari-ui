# Kurulum

mari-ui; React 18+ kullanan her web projesinde çalışır (Next.js, Vite, Remix…). Component'ler sunucu bileşeni (RSC) uyumludur: hook ya da tarayıcı API'si kullananlar kendi `"use client"` işaretini taşır.

## 1. Paketler

```bash
pnpm add @mari-ui/components @mari-ui/core @mari-ui/tokens
```

İsterseniz CLI bunu sizin için yapar ve `mari-ui.config.json` ile AI ajan kurallarını da oluşturur (bkz. **Başlarken / AI Kuralları**):

```bash
npx @mari-ui/cli init
```

## 2. Stil ve fontlar

Projenizde Tailwind olup olmadığına göre **iki yoldan biri** — ikisini birden değil (`npx @mari-ui/cli init` hangisinin sizin için doğru olduğunu söyler).

### Tailwind v4 kullanıyorsanız (önerilen)

mari-ui sınıflarını **sizin Tailwind'iniz** derler: her sınıf ve sıfırlama (preflight) sayfada tek kez bulunur, `--spacing` tek. Global CSS dosyanızda:

```css
@import "tailwindcss";
@import "@mari-ui/components/tailwind.css";
@import "./mari-ui-theme.css"; /* npx @mari-ui/cli theme çıktısı — kendi config'iniz varsa */
```

Tema bütün uygulamaya uygulanır: font, `rounded-*` ölçeği ve yoğunluk (`--spacing`) mari-ui'dan gelir; kendi sayfalarınızda da `bg-mari-surface`, `text-mari-muted`, `shadow-mari-md` gibi sınıfları kullanabilirsiniz. **`@mari-ui/components/styles.css`i ayrıca import etmeyin** — aynı sınıfları ve sıfırlamayı ikinci kez yükler, sonra yüklenen kazanır.

### Tailwind kullanmıyorsanız

Hazır derlenmiş CSS:

```tsx
import "@mari-ui/tokens/fonts.css"; // isteğe bağlı — Geist, Manrope, Geist Mono yerel dosyaları
import "@mari-ui/components/styles.css";
import "./mari-ui-theme.css"; // npx @mari-ui/cli theme çıktısı — kendi config'iniz varsa
```

### Tailwind v3

Desteklenmez: mari-ui teması v4 söz dizimiyle (`@theme`, `@source`, `@utility`) yazılı, v3 bunları derlemez. `npx @tailwindcss/upgrade` projeyi büyük ölçüde otomatik v4'e taşır. Geçici olarak derlenmiş `styles.css` çalışır ama v3 sınıflarınızla çakışabilir.

### Ortak notlar

- `fonts.css` ağ isteği yapmaz; yüklemezseniz sistem fontu kullanılır. Tasarım kişiliği seçtiyseniz fontlarının Google Fonts bağlantısını `npx @mari-ui/cli theme` basar.
- `mari-ui.config.json` proje kökünde durur; yalnız `npx @mari-ui/cli theme` okur (uygulama çalışırken okunmaz). Config'i değiştirince komutu tekrar çalıştırın — `package.json`'a `"prebuild": "mari-ui theme"`, CI'a `npx @mari-ui/cli theme --check` ekleyebilirsiniz.

## 3. Kullanım

Her component kendi yolundan içe aktarılır; kullanmadıklarınız paketinize girmez.

```tsx
import { Button } from "@mari-ui/components/button";
import { Input } from "@mari-ui/components/input";
import { Card } from "@mari-ui/components/card";

export function Giris() {
  return (
    <Card title="Giriş yap">
      <Input placeholder="E-posta" type="email" />
      <Button color="primary" block>Devam et</Button>
    </Card>
  );
}
```

Bildirim (`useToast`) kullanacaksanız uygulamanın kökünü `ToastProvider` ile sarın:

```tsx
import { ToastProvider } from "@mari-ui/components/toast";

<ToastProvider>{children}</ToastProvider>
```

## Next.js (App Router)

Kayıtlı tema (açık/koyu, vurgu rengi, yoğunluk) sayfa çizilmeden önce uygulansın diye `getThemeScript()` `<head>`e konur — yoksa koyu tema seçen kullanıcı açılışta bir an açık tema görür.

```tsx
// app/layout.tsx — globals.css yukarıdaki iki yoldan birini içerir
import "./globals.css";
import { getThemeScript } from "@mari-ui/tokens";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    // Script <html>'e data-theme yazar; React'in uyuşmazlık uyarısını bu öğe için susturur.
    <html lang="tr" suppressHydrationWarning>
      <head>
        <script dangerouslySetInnerHTML={{ __html: getThemeScript() }} />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

Bağlantılar düz `<a href>`dir (router'a bağlı bir Link component'i yok). Menülerde (BasicMenu, MegaMenu, Sidebar) sayfa yenilemeden geçiş için router'ınızı `onNavigate` ile verirsiniz; dış adresler ve `target="_blank"` router'ı otomatik atlar:

```tsx
"use client";
import { useRouter } from "next/navigation";
import { Sidebar } from "@mari-ui/components/menu";

export function AppSidebar() {
  const router = useRouter();
  return <Sidebar data={menu} onNavigate={(route) => router.push(route)} />;
}
```

## Vite

```tsx
// main.tsx — index.css yukarıdaki iki yoldan birini içerir
import "./index.css";
```

Tema script'ini `index.html`e build sırasında eklemek için:

```ts
// vite.config.ts
import { defineConfig } from "vite";
import { getThemeScript } from "@mari-ui/tokens";

export default defineConfig({
  plugins: [
    {
      name: "mari-ui-theme-script",
      transformIndexHtml: () => [{ tag: "script", children: getThemeScript(), injectTo: "head-prepend" }],
    },
  ],
});
```
