# Yerel fontlar

Google Fonts resmi deposundan alınan değişken TTF dosyaları (2026-09-27):

- Geist: https://github.com/google/fonts/tree/main/ofl/geist
- Geist Mono: https://github.com/google/fonts/tree/main/ofl/geistmono
- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope

SIL Open Font License 1.1 metinleri her fontun yanında korunmuştur.
Web'de `@mari-ui/tokens/fonts.css` ile isteğe bağlı yüklenir. TTF dosyaları
native uygulamaların font kaydında da kullanılabilir; uygulama font yüklemesini
tamamladıktan sonra bileşenleri göstermelidir. React Native platformlarında
değişken font ve ağırlık kaydını uygulamanızın hedef cihazlarında doğrulayın.
