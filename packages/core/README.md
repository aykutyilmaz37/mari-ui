# @mari-ui/core

mari-ui'ın web (`@mari-ui/components`) ve React Native (`@mari-ui/native`) arasında paylaşılan headless katmanı: ortak eksen tipleri (`ColorRole`, `Size`, `Variant`, `Radius`, `Placement`), variant çözümleme (`resolveColorVariant`), `cn()` ve headless hook'lar. Render etmez.

Genellikle doğrudan değil, `@mari-ui/components` ya da `@mari-ui/native` ile birlikte kurulur:

```bash
pnpm add @mari-ui/components @mari-ui/core @mari-ui/tokens
```

Ayrıntı: [mari-ui deposu](https://github.com/aykutyilmaz37/mari-ui#readme). Lisans: MIT.
