# mari-ui logo

`mari-ui-logo.png`: şeffaf arka planlı, 2172 × 724 piksel yatay logo. Açık zeminler için hazırlanmıştır.

Mari, Marisa isminden gelir. İki yumuşak formun birleştiği m işareti, bu kişisel bağı ve web / React Native'in ortak bir tasarım sisteminde buluşmasını temsil eder.

Tasarım, projenin mevcut paletini temel alır: açık mavi `#88BDF2`, çelik mavisi `#6A89A7` ve koyu mavi-gri `#384959`. Üretken görsel çıktısındaki piksel renkleri bu referanslardan küçük farklılıklar gösterebilir.

Bu dosya raster PNG'dir; SVG değildir. En-boy oranını koruyun ve açık zemin üzerinde kullanın. Önerilen dokümantasyon genişliği: 320 px.

Üretim: yerleşik imagegen aracı. Kullanılan tam istem `prompt.txt` dosyasındadır.
